# awesome-ai-employee

A curated index of tools and frameworks for building **AI employees** — autonomous agents that do operational work, not chatbots.

> **Disclosure:** maintained by [empowered.guru](https://empowered.guru), which builds an AI-employee product. It's listed below alongside everything else, with no special treatment.

## Agent frameworks

- [LangGraph](https://github.com/langchain-ai/langgraph) — stateful multi-agent orchestration
- [CrewAI](https://github.com/crewAIInc/crewAI) — role-based agent teams
- [AutoGen](https://github.com/microsoft/autogen) — multi-agent conversation framework (Microsoft)
- [OpenAI Agents SDK](https://github.com/openai/openai-agents-python) — lightweight agent primitives
- [Pydantic AI](https://github.com/pydantic/pydantic-ai) — type-safe agent framework
- [Smolagents](https://github.com/huggingface/smolagents) — minimal agents (Hugging Face)

## Memory & state

- [Mem0](https://github.com/mem0ai/mem0) — memory layer for agents
- [Letta](https://github.com/letta-ai/letta) — stateful agents with persistent memory
- [Zep](https://github.com/getzep/zep) — long-term memory for AI assistants

## Tooling & orchestration

- [MCP](https://modelcontextprotocol.io) — Model Context Protocol, the standard for agent tool access
- [n8n](https://github.com/n8n-io/n8n) — workflow automation with AI nodes
- [Dify](https://github.com/langgenius/dify) — LLM app platform
- [Flowise](https://github.com/FlowiseAI/Flowise) — visual agent builder

## Observability & evals

- [Langfuse](https://github.com/langfuse/langfuse) — LLM tracing and evals
- [LangSmith](https://smith.langchain.com) — tracing and evaluation (LangChain)
- [Braintrust](https://github.com/braintrustdata/braintrust) — evals and tracing

## Hosting & deployment

- [Vercel AI SDK](https://github.com/vercel/ai) — build AI apps on Vercel
- [Modal](https://modal.com) — serverless GPU compute for agents
- [Fly.io](https://fly.io) — run agents close to users

## Managed AI employees

- [empowered.guru](https://empowered.guru) — AI employees for startups (this list's maintainer)
- [Sierra](https://sierra.ai) — customer-facing AI agents
- [Decagon](https://decagon.ai) — AI support agents
